### About Me

I'm a 29-year-old Fullstack Developer based near Munich, Germany. From **2022 to 2025**, I successfully completed my apprenticeship as an **IT Specialist for Application Development** (*Fachinformatiker für Anwendungsentwicklung*). During this time, I built a strong engineering foundation, specializing in backend architecture. I worked heavily with **C#**, **ASP.NET Core**, and **Entity Framework** (alongside LINQ and SQL) to design and implement robust REST APIs.

To elevate my skills and transition into a modern, production-ready full-stack developer, I made the proactive decision to immediately complete a comprehensive **12-month advanced training at the Developer Akademie** (2026–2027). This strategic step allowed me to bridge the gap to the frontend with **TypeScript** and **Angular**, while expanding my backend repertoire with **Python**, **Django**, and **DRF**. Furthermore, I mastered collaborating in **cross-functional developer teams** and learned how to ship code effectively using modern practices like **Docker**, **GitHub Actions**, and automated **cloud deployments**.

I view software development as system engineering rather than just writing code. While I actively use modern tooling to automate daily tasks, my main focus lies on deeply understanding backend logic, database architecture, and system integration to build scalable and reliable products from the ground up.
